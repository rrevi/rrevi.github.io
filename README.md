# rrevi.github.io

Personal website and software development journal of **Rafael Revi** — Principal Applications Engineer & Platform Lead.

Live at: [https://rrevi.github.io](https://rrevi.github.io)

---

## Tech Stack & Architecture

- **Framework**: [Astro 5](https://astro.build/) (Static Site Generation / Content Layer API)
- **Design System**: Rivian OS (Gen 2 & R2 Platform) aesthetic ("Digital Adventure Gear")
  - Stadium pill geometry, high-precision 1.5px cel-shaded outlines
  - Dual Palette: Expedition Slate (`#121519`) & Glacier Sand (`#f5f2eb`) with Compass Yellow (`#f5b335`) accents
  - Client-side View Transitions (`<ClientRouter />`)
- **Typography**: Self-hosted Geist Sans & Geist Mono
- **Syntax Highlighting**: Shiki dual-theme (`kanagawa-wave` & `kanagawa-lotus`) with interactive terminal cockpit wrappers and one-click copy buttons
- **Feeds & SEO**: `@astrojs/rss`, `@astrojs/sitemap`, OpenGraph metadata, and Cloudflare Analytics

## Directory Structure

```text
├── src/
│   ├── content/
│   │   ├── blog/          # All 26 markdown articles (1:1 permalink parity)
│   │   └── experience/    # Chronological career logs (YYYY.md per year)
│   ├── components/        # Header, ThemeToggle, etc.
│   ├── layouts/           # BaseLayout, PostLayout
│   ├── pages/             # Routes: /, /about, /:slug, /404, /rss.xml
│   ├── styles/            # global.css (Rivian OS tokens and responsive styling)
│   ├── utils/             # Reading time calculations, date formatters, posts
│   └── content.config.ts  # Type-safe Astro 5 Content Collections schemas
├── public/                # Favicons, web manifest, social SVG sprite assets
├── script/                # Scripts-to-Rule-Them-All lifecycle convention
└── dist/                  # Static HTML output generated by Astro
```

## Scripts & Workflow

All scripts adhere to GitHub's *Scripts to Rule Them All* pattern:

| Script | Purpose |
| :--- | :--- |
| `script/setup` | Initial machine setup; invokes `script/bootstrap` |
| `script/bootstrap` | Installs dependencies via npm |
| `script/server` | Starts the Astro development server (`astro dev`) at `http://localhost:4321` |
| `script/build` | Builds production static assets into `dist/` |
| `script/cibuild` | CI validation script; builds and verifies `dist/index.html` presence |

## Adding Content

### 1. New Blog Post
Create a Markdown file in `src/content/blog/` following the naming convention:
```markdown
---
title: "Your Post Title"
date: YYYY-MM-DD
intro: "Brief summary of the article"
---

Your markdown content here...
```

### 2. New Career Year (About Page)
To record a new year in Experience, add a file in `src/content/experience/{YEAR}.md`:
```markdown
---
year: 2026
role: "Principal Applications Engineer & Platform Lead"
period: "2021 – Present"
---

- Your milestone highlights for the year...
```
The `/about` page automatically sorts all years chronologically and groups them by career era.
